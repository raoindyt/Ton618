# TON 618 Music Player

Красивый музыкальный плеер для Windows с поиском и скачиванием музыки из интернета.

## ✨ Возможности

- 🎵 **Поиск музыки** — ищите треки с YouTube Music и SoundCloud прямо в приложении
- 📥 **Скачивание** — загружайте любимые песни в высоком качестве (MP3 320kbps)
- 📚 **Личная библиотека** — все скачанные треки хранятся локально
- 🎯 **Умные рекомендации** — предлагает музыку на основе ваших прослушиваний
- 📋 **Плейлисты** — создавайте и управляйте коллекциями треков
- 🎚️ **Эквалайзер** — настройте звук под себя
- 🌌 **Красивый дизайн** — космический интерфейс с анимацией звёзд
- ⚡ **Быстрый поиск** — мгновенная фильтрация по всей библиотеке

## 🚀 Установка

1. Скачайте файл `TON 618 Music Player Setup X.X.X.exe` с GitHub
2. Запустите установщик
3. Следуйте инструкциям на экране

После установки ярлык появится на рабочем столе и в меню Пуск.

## 🎮 Как использовать

### Основное окно
- **Главная** — поиск музыки в интернете
- **Библиотека** — ваши скачанные треки
- **Рекомендации** — персональные предложения
- **Плейлисты** — управление коллекциями
- **Эквалайзер** — настройка аудио
- **Настройки** — внешний вид и параметры

### Поиск музыки
1. Введите название песни или исполнителя в поисковую строку
2. Выберите источник: YouTube Music или SoundCloud
3. Нажмите на трек для прослушивания
4. Кликните "Скачать" чтобы добавить в библиотеку

### Управление плеером
- **Пробел** — воспроизведение/пауза
- **Стрелки влево/вправо** — предыдущий/следующий трек
- **Колёсико мыши** — громкость
- **Двойной клик** по треку — добавить в очередь

## 🎨 Персонализация

### Внешний вид
- Включите "Фоновая галактика" в настройках для красивого звёздного неба
- Выберите качество скачивания: от 128kbps до лучшего качества

### Рекомендации
- Включите интеграцию с Last.fm для лучших предложений
- Настройте уровень разнообразия рекомендаций
- Укажите любимые жанры и исключите live-записи

## 📝 Системные требования

- **ОС**: Windows 10/11 (64-bit)
- **Процессор**: любой современный
- **Память**: 512 MB RAM
- **Диск**: 200 MB свободного места
- **Интернет**: нужен для поиска и скачивания музыки

## 🔧 Поддержка

Если возникли проблемы:
1. Проверьте интернет-соединение
2. Перезапустите приложение
3. Убедитесь, что антивирус не блокирует скачивание
